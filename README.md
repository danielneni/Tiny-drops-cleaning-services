TINY DROP CLEANING SERVICES

Project Description

Tiny Drop Cleaning Services is a responsive business website designed to provide information about a professional cleaning company.

The website allows visitors to explore the company’s background, view available cleaning services, check pricing packages and contact the business.


Website Pages

1. Home: Introduces Tiny Drop Cleaning Services.
2. About: Provides information about the company, its mission and vision.
3. Services: Displays the cleaning services and available packages.
4. Contact: Provides contact information and a contact form.

Technologies Used

* HTML – Used to structure the website.
* CSS – Used to style and design the website.
* JavaScript – Used to implement interactive features and validate the contact form.

Responsive Design

The website is designed to work on:

* Mobile phones
* Tablets
* Desktop and laptop computers

CSS media queries are used to adjust the website layout to different screen sizes.
